# **App Name**: Fusion8

## Core Features:

- User Registration & Authentication: Allow users to register as students, teachers, or admins and authenticate via a login system, directing them to appropriate dashboards.
- Course Catalog: Publicly display available courses with detailed course pages prompting enrollment.
- Student Dashboard: Provide students with access to enrolled courses, video lessons, a notification center, profile/portfolio page, assignment submission page and the community project hub.
- Teacher Dashboard: Enable teachers to manage their courses through a course builder interface, add/edit lessons, create quizzes, schedule and manage live classes, view/grade assignments using the gradebook feature, manage the live class attendance logs and access their notification center.
- Admin Dashboard: Grant admins user management capabilities (approving teachers), platform-wide course management tools, and access to platform analytics.
- Community Project Hub: Provide students the ability to form teams for community projects and allow teachers/admins to oversee project workflows using a project board. Give each team a project workspace to manage documents.
- AI-Powered Content Summaries: Use generative AI to provide summaries of courses or video lessons for students who prefer learning that way. Students can copy this into other tools as well.

## Style Guidelines:

- Primary color: Black (#000000) for a sleek, modern look.
- Secondary color: White (#FFFFFF) to provide contrast and readability.
- Accent color: Red (#FF3A22) for CTAs, highlights, and important notifications, creating a sense of urgency and grabbing attention.
- Body: 'Roboto', a clean and readable sans-serif font, ensuring a comfortable reading experience.
- Headline: 'Montserrat', a bold and modern sans-serif font, providing a strong visual hierarchy.
- Use a minimalist icon set with a focus on clarity and usability. Icons should be easily recognizable and complement the overall design aesthetic.
- Implement a grid-based layout with a clear visual hierarchy. Prioritize key information with strategic use of whitespace and intuitive navigation to guide users efficiently through the platform's features and content.
- Incorporate subtle transitions and animations to enhance user engagement and provide feedback on interactions. Animations should be smooth and purposeful, contributing to a seamless and enjoyable experience throughout the Fusion8 platform.
